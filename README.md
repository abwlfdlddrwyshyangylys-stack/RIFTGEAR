# RIFTGEAR ⚡

فروشگاه استاتیک تجهیزات گیمینگ — سفارشی‌شده برای ابوالفضل.

## امکانات
- فروشگاه کامل استاتیک (HTML/CSS/JS خالص، بدون وابستگی)
- دوزبانه: فارسی (RTL) ↔ انگلیسی (LTR) با یک دکمه
- ۱۷ محصول در ۷ دسته: ماوس، کیبورد، هدست، دسته، صندلی، کنسول، بازی
- جستجو + فیلتر دسته + مرتب‌سازی قیمت
- سبد خرید کامل با localStorage (افزودن/تغییر تعداد/جمع کل)
- تم تاریک نئونی با پنل‌های گوشه‌بُر (HUD)
- ریسپانسیو موبایل + پشتیبانی `prefers-reduced-motion`

## اجرا محلی
```bash
python3 -m http.server 8080
# http://localhost:8080
```
